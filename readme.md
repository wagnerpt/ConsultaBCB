# ConsultaBCB

Este projeto busca normas do Banco Central e armazena os dados em um banco de dados SQL Server.

## Instalação

1. Clone o repositório:
   ```sh
   git clone https://github.com/seu-usuario/ConsultaBCB.git
   cd ConsultaBCB

2. Crie um ambiente virtual e ative-o:
``` sh
python -m venv venv
source venv/bin/activate  # No Windows use `venv\Scripts\activate`
```

3. Instale as dependências:
``` sh
pip install -r requirements.txt
```

4. Configure as variáveis de ambiente no arquivo

5. Execute o script principal:
``` sh
python src/bcb_to_excel.py
```
